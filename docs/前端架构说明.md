# 健康商城前端（管理端）架构说明

> ShopSuite 商城管理后台（admin），Vue CLI 5 工程的 Vue 3 + TypeScript + Element Plus 单页应用。
> 对接后端 mall-backend（Spring Boot，端口 8100）的 `/manage/**`（管理端）与 `/front/**`（C 端）接口。
> 文档生成时间：2026-09-20（基于当前代码分析）

## 1. 技术栈

| 分类 | 选型 | 版本 |
|---|---|---|
| 框架 | Vue 3 + TypeScript | 3.4.38 / 5.5.4 |
| 构建 | @vue/cli-service（webpack 5.93） | 5.0.8 |
| UI 组件库 | Element Plus + @element-plus/icons-vue | 2.8.0 |
| 状态管理 | Pinia | 2.2.2 |
| 路由 | vue-router | 4.4.3 |
| 请求 | axios + qs + js-cookie + jsencrypt | 1.7.4 |
| 国际化 | vue-i18n | 9 |
| 图表 | echarts | 5.5.1 |
| 富文本 | wangeditor、vue-quill | — |
| 其他 | dayjs、decimal.js（金额计算）、nprogress、mockjs | — |
| 样式 | SCSS（无 Tailwind） | sass 1.77 |
| 按需加载 | unplugin-auto-import / unplugin-vue-components / unplugin-element-plus | Vue API 与 `el-*` 组件免 import |

**命令**（package.json scripts）：`npm run dev`（dev 模式，端口 16000）、`npm run build`（prod 模式，输出到 `admin/` 目录）、`lint`、`test:unit`（jest，暂无测试文件）。

```
mall-frontend/

├── deploy.sh                   # 部署脚本
```

## 3. 路由：后端驱动的动态路由

- `src/router/index.ts` 静态路由仅 `constantRoutes`：`/login`、`/callback`、`/403`、`/404`；hash/history 模式由 `isHashRouterMode` 配置决定。
- **菜单/路由由后端下发**：`src/store/modules/routes.ts` 调用 `src/api/router.ts` 的 `getList()` → 请求 `/manage/admin/menu/tree`，再经 `src/utils/routes.ts` 的 `convertRouter`（字符串路径 → 组件）与 `filterRoutes`（按权限过滤）生成路由表，`resetRouter()` 注册。
- 守卫流程 `src/router/permissions.ts`：有 token 且路由未初始化时，先 `getSysInfo` 取站点配置 → `getUserInfo` → `setRoutes("all")`。
- 页面模块（`src/views/`）：`admin`(菜单/角色/管理员)、`account`(会员)、`pt`(商品：productBase/Spec/Brand/Category/Comment)、`trade`(orderBase/Invoice/Return)、`pay`(充值/提现/积分)、`shop`(物流/运费)、`cms`(文章)、`analytics`(统计)、`sys`(配置/字典/日志/图库)、`page/sellerApp`、`index`。

## 4. 状态管理（Pinia）

`src/store/modules/`：

| module | 职责 |
|---|---|
| `user.ts` | token、登录/登出、用户信息 |
| `routes.ts` | 动态菜单/路由生成 |
| `acl.ts` | 按钮级权限 |
| `settings.ts` | 主题、站点配置 |
| `tabs.ts` | 多标签页 |
| `errorLog.ts` | 错误日志收集 |

统一注册于 `src/store/index.ts`。

## 5. 网络层

- **封装**：`src/utils/request.ts` 创建 axios 实例，baseURL 取自 `@/config`，默认 `Content-Type: application/x-www-form-urlencoded`。
- **请求拦截**：注入 `Bearer token`。
- **响应拦截**（后端统一返回 status 200/250）：250 且 401 → 跳登录；250 且 402 → 调 `src/api/refreshToken.ts` 刷新 token 并**队列重试**原请求；403 → 跳 `/403`；其余错误统一 `gp.$message` 提示并写 errorLog。
- **URL 集中管理**：全部接口地址定义在 `src/config/url.config.js`（api 前缀 + 按模块的对象分组）；`src/api/**.ts` 仅做参数化封装，如 `src/api/pt/productBase.ts`。
- **环境变量**：`.env`（密钥）、`.env.dev`、`.env.prod`。健康版定制：`VUE_APP_API_URL=""`（同源部署，由 nginx 反代后端 8100）、`VUE_APP_ADMIN_URL=http://127.0.0.1/admin`。

## 6. 样式与主题

- SCSS 变量：`library/styles/variables.scss` 经 `vue.config.js` 的 `additionalData` 全局注入，另有 `library/styles/ms.scss`、`ms-themes.scss`。
- 主题开关：`src/config/theme.config.js`（layout 默认 `vertical`、themeName `blue-black`、tabs/progress 等开关）；Element Plus 按需加载换肤。

## 7. 构建与部署

- `vue.config.js`：
  - alias：`@`→src、`~`→工程根、`/#`→types、`@sslib`→library、`@gp`→library/plugins/ms；
  - 插件链集中在 `library/build/index.ts`（createVuePlugin + createChainWebpack，含 auto-import、svg-sprite）；
  - PWA（workbox）开启；`productionSourceMap: false`。
- 产物输出到 **`admin/`** 目录（`src/config/cli.config.js` 的 `outputDir`），开发端口 **16000**。
- 部署：`deploy.sh`；支持 docker 构建。

## 8. 组件规范

| 层级 | 位置 | 示例 |
|---|---|---|
| 框架级（跨项目复用） | `library/components/Ms*` | MsAppMain、MsHeader、MsSideBar、MsMenu、MsBreadcrumb、MsTabs、MsUpload 类、MsTree、MsSearchBox |
| 布局 | `library/layouts/MsLayoutVertical` | 主布局（对应 theme.layout 配置） |
| 业务级 | `src/plugins/` | MsUpload、MsRichEditor、MsChart、ProductTable、OrderState、PaymentChannel |

命名约定：组件 PascalCase 且带 `Ms` 前缀；`views` 按模块目录 + `index.vue`；api/store 文件用 camelCase 的 `.ts`。

## 9. 与后端的对应关系

| 前端 | 后端 |
|---|---|
| `src/api/<域>/` | `mall-server-core` 的 `<域>/controller/manage/**`（管理端）或 `controller/front/**` |
| 动态菜单 `/manage/admin/menu/tree` | `admin` 域菜单管理（`sys` 菜单表配置） |
| 登录/刷新 token | `account` 域 + JWT（后端 `common/security/`） |
| 统一返回 200/250 | 后端 `core/web/CommonRes.java` |
